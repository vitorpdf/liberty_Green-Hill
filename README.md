# liberty

Jogo de plataforma 2D desenvolvido, com uma única fase inspirada em Green Hill Zone.

## 🎮 Sobre o jogo

Corra pelos mares de morros, colete anéis e destrua os vilões. Alcance a placa de chegada com suas vidas intactas.

O objetivo é atravessar a fase, saltando entre plataformas e enfrentando os mini vilões, antes de perder as três vidas. Caminhos elevados permitem explorar o cenário e coletar mais anéis.

Este projeto foi desenvolvido para a disciplina de Programação Web da Universidade Federal de Lavras, aplicando estruturação de páginas, estilização, manipulação do DOM, tratamento de eventos e lógica de programação.

## 🎮 Como jogar

1. Abra o jogo e clique em **Jogar**.
2. Use as setas para controlar o personagem e **Espaço** para saltar.
3. Colete anéis e salte sobre os vilões para derrotá-los.
4. Alcance a placa de chegada para vencer.

| Controle | Ação |
| --- | --- |
| Seta esquerda / direita | Mover o personagem |
| Seta para cima | Olhar para cima quando parado |
| Seta para baixo | Agachar quando parado ou rolar em movimento |
| Espaço | Saltar; manter pressionado permite um salto mais alto |
| Enter | Pausar ou retomar a partida |
| Esc | Voltar à tela inicial |
| Botão Reiniciar | Recomeçar com três vidas e zero anéis |

O jogo possui um único personagem jogável e utiliza teclado. Ao sair da janela ou trocar de aba, a partida é pausada automaticamente.

### Execução local

Não é necessário instalar dependências, compilar o projeto ou configurar um servidor.

1. Baixe os arquivos do repositório ou faça seu clone.
2. Mantenha index.html, style.css e game.js na mesma pasta.
3. Preserve a pasta assets com os arquivos PNG.
4. Abra index.html em um navegador moderno com suporte a Canvas e JavaScript.
